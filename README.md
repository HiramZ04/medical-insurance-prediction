# medical-insurance-prediction

## Setup Instructions
1. Clone the repository and navigate to the project directory.
2. Compile the frontend:
   - Navigate to the `frontend` directory and run `npm install` to install the dependencies.
   - Run `npm run build` to compile the frontend assets into the `dist` directory.
3. Navigate to the `backend` directory and run `npm install` to install the dependencies.
4. Start the server by running `node server.js`. The web server will be running on `http://localhost:8080`.
5. Open a web browser and navigate to `http://localhost:8080` to access the application.
